# Choice Pain

Astro + React islands + Framer Motion + Tailwind CSS v4.

## Start
```bash
npm install
npm run dev
```

## Structure
- `src/pages` – routes (Astro)
- `src/layouts` – page layouts
- `src/components/astro` – static components (no JS shipped)
- `src/components/react` – React islands (Framer Motion animations)
- `src/data` – content as data
- `src/styles/global.css` – Tailwind import + theme
